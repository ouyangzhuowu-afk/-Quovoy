# 14 天付费试点准备包

状态：准备材料。尚无真实客户数据、真实效率结果或付款证明。本文中的价格和门槛均为待测试假设，不能在演示中表述为已实现成果。

## 可直接用于商谈的范围说明

“我们用 14 天测试：在一个机械零部件／金属加工件品类、最多 30 份询价范围内，帮助你们整理邮件和附件、核对产品规格、计算报价、准备英文草稿并跟进。每份报价由销售和主管审核，邮件由你们自行发送。交付可追溯的询价记录、报价版本及一份同时列出成功、失败和人工兜底案例的效率报告。工程图、可制造性和交付承诺仍由你们确认。”

上限按独立业务询价计数，同一询价的附件和重试不重复计数。试点连续纳入符合事先约定品类的询价，包含难例；超过 30 份时按到达顺序截止。历史回放与新到询价分别标记，不混报真实性。培训用合成样本另列，不计入 30 份真实结果。

## 14 天安排

| 时间 | 具体活动 | 可检查产物 |
| --- | --- | --- |
| 第 1–2 天 | 访谈，固定范围、价格提案、字段真值口径、工时起止点与数据许可；合成数据培训 | 双方认可的试点范围，空白效率表，样本登记 |
| 第 3–4 天 | 先用少量历史询价双流程回放，核对计时与标注方法，修复操作障碍 | 配对原始工时、来源真值及问题登记 |
| 第 5–10 天 | 按到达顺序处理剩余询价，总计不超过 30 份；每天保留失败、返工、审批与人工兜底记录 | 完整样本登记和版本／审计引用 |
| 第 11–12 天 | 由未操作该次提取的业务专家复核冻结真值，复查错误、等待与缺失数据 | 字段级真值表、错误裁定与缺失原因 |
| 第 13 天 | 计算配对结果、病例分层、使用问题、净时间价值与费用敏感性 | 可回查效率报告及限制 |
| 第 14 天 | 共同复盘，明确付费／续费／延长补测／停止，约定下一范围 | 决策、理由、负责人；实际收款凭证另行留存 |

训练／规则变化应记录发生时间和版本，变化前后的结果分开列示。未收足样本仍在第 14 天出具结果，明确样本不足，不延长到“凑出好结果”。

## 访谈提纲（约 25 分钟）

1. 请拿最近一份询价，从收到到报价发出逐步演示。谁参与？在哪些地方复制、等待和返工？
2. 上个月有多少询价、几种品类、多少产品行？邮件、PDF、Excel、扫描图分别占多少？
3. 最近一次报价错误或漏跟进是什么？如何发现，带来什么成本？请给具体案例。
4. 哪些规格缺失会阻止报价？哪些可以先出草稿？谁有权解释图纸和承诺交期？
5. 审批看哪些字段和条款？改数量、汇率、英文邮件后是否需要重新审批？
6. 目前一份简单／复杂询价各花多少主动操作时间？哪些时间是在等客户或供应商？能否用真实记录核对估计？
7. 哪些数据不能交给外部模型？需要何种部署、权限、保留和删除方式？
8. 若记录显示每月节省 X 小时，谁决定预算？预算来自哪里？怎样的收费和退出条件能启动 14 天试点？
9. 即使省时间，什么情况会让你停止使用？请按错误风险、学习成本、流程成本、价格分别说明。

访谈中记录原话和实例；“觉得不错”“愿意试试”不记作付款意向已验证。需要明确金额、决策人、下一动作和时间。

## 收费假设与价值核对

初始提案为 **人民币 1,500 元／14 天／一家企业／一个品类／最多 30 份询价**，包含初始配置、一次培训、人工复核流程和效率报告。它是访谈用假设，不是市场价格结论，也不是已成交记录。续用提案可测试 **人民币 999 元／月**，先复核客户实际月量、支持成本和模型成本，再约定用量与服务边界。费用、付款时间及未完成范围的处理方式需客户明确接受后才能收取；本项目不实现收费操作。

价值核对使用客户确认的全成本小时费率：

```text
预计月度人工价值 = 每份询价配对节省时间的中位数（分钟） × 可覆盖的真实月询价量 ÷ 60 × 人工小时成本
预计月度净价值 = 预计月度人工价值 - 月费 - 新增模型费用 - 新增维护／复核工时成本
```

同时展示低／中／高询价量情景，保留负节省案例。等待客户／供应商缩短不能折算为节省人工费。避免把节省时间全部视作可削减工资；客户还需确认时间能否转用于有效工作。付款已验证以实际入账或可核实支付记录为准，口头认可、合同草稿和演示均不替代。

## 效率和质量记录方法

使用 [pilot-measurements.csv](pilot-measurements.csv)，每行是一份询价的配对记录。模板仅有列名，不预填数字，空白表示未测量。字段字典如下：

| 列 | 定义 |
| --- | --- |
| `rfq_id`, `source_reference`, `quote_version` | 去标识询价 ID、原件／系统记录引用、被测版本。引用不能包含明文凭证或无保护的客户文件 |
| `data_kind`, `category`, `received_at` | `real_historical`／`real_live`／`synthetic_training`，唯一品类、收到时间（ISO 8601 含时区） |
| `included`, `exclusion_reason` | 是否在预定总体内；排除只能依据预先规则，失败不可因表现差而排除 |
| `pair_method`, `baseline_operator`, `assisted_operator`, `order` | 同原件独立操作或匹配方式、操作员代号、先基线／先辅助，控制学习顺序 |
| `baseline_active_min`, `assisted_active_min` | 两种方式从开始整理到可批准报价与英文草稿完成的主动人工分钟，含检查、修正、返工和主管操作；多人时间相加 |
| `baseline_customer_wait_min`, `assisted_customer_wait_min` | 两种方式等待客户的经过时间，单独列示 |
| `baseline_supplier_wait_min`, `assisted_supplier_wait_min` | 两种方式等待供应商的经过时间；并行等待另注明，不能相加充当周期 |
| `key_fields_total`, `initial_correct_fields`, `manual_edited_fields`, `final_error_fields` | 真值可判定的关键字段总数、初始正确数、人工改动的唯一字段数、最终残余错误数 |
| `truth_reference`, `adjudicator` | 冻结字段真值和逐字段来源的引用、独立复核人代号 |
| `model_mode`, `model_version`, `manual_fallback`, `result` | 演示／规则／真实模型，版本，是否转人工，完成／失败／未完成 |
| `review_logged_seconds`, `task_completed_at` | 应用自报审核片段秒数与任务完成时间；不能代替完整人工计时 |
| `hourly_cost_cny`, `notes` | 客户确认的人工成本假设与异常／缺失／中断原因 |

计时先固定起止点，暂停外部等待与非任务中断，但人工电话沟通、重试和修正计入主动时间。无人工介入的模型等待单独记录于备注，不算人工，也不能隐藏整体响应延迟。应用审核秒数只作交叉检查，不能宣称覆盖所有操作。

优先使用相同原件进行配对：由两位经验相近的操作员独立完成，轮换基线／辅助分工，彼此不看结果。若同一人先后处理，交替顺序并记忆学习偏差；若只能选相似历史记录，写明匹配变量和不可排除的差异，不将它称为严格因果实验。

每个纳入询价 i：

```text
节省分钟_i = 基线主动分钟_i - 辅助主动分钟_i
相对节省率_i = 节省分钟_i / 基线主动分钟_i（基线 > 0 才可计算）
总体报告 = 配对节省分钟中位数、配对相对节省率中位数、四分位区间、有效配对数
初始关键字段准确率 = Σ初始正确字段 / Σ有真值关键字段
最终错误率 = Σ最终错误字段 / Σ有真值关键字段
```

零基线、缺失计时、未完成和人工兜底仍列在总体登记中；给出无法配对数及原因，不能填零或从样本数消失。同时列总主动时间、最慢案例、失败率、需人工兜底数和每类来源样本数。所有百分比伴随分子／分母和样本数。≤30 份试点不足以证明普遍效果。

在运行提取前冻结逐字段真值：询价 ID、产品行 ID、字段、预期值、允许的规范化、原文定位、判定人。关键字段清单按品类预定；源文件明确缺失的字段单列为“缺失识别”，不把大量空字段算作准确率成功。漏提、多提和挂错产品行均计错。争议字段保留原因与裁定记录。人工改动可能只是格式、补充客户新信息或风格偏好，**人工修改率不等于模型错误率**；初始错误必须对照冻结真值判断，最终错误在人工审核后另评。

## 续费／继续／停止条件

以下门槛须在第 2 天前与客户确认，结束时不为迎合结果事后更改：

- 价值目标：配对人工时间相对节省率中位数达到 50%，且真实适用量下预计净价值为正。未达到时先报告实际结果和主要耗时点。
- 质量目标：真实、可判定关键字段初始准确率达到 90%，明确分母、样本数和品类限制；人工审批后无已知数量、单位、币种、总额或关键规格错误。
- 流程底线：跨组织访问、未批准正式导出、失效批准继续使用、未经确认自动发送等核心风险零容忍，出现即暂停受影响路径并复核。
- 支付证据：至少一个客户对清楚限定的范围实际支付。只有口头意向则记“待验证”。
- 续费：价值与质量达到双方门槛、负责人持续使用且预算人接受明确续费报价。样本不足可约定有限补测；没有可量化价值、关键风险未修复或无预算时停止，不强行扩展品类。

最终报告必须把技术验收、真实模型评价、流程效果和收款四类证据分开。演示可用不代表生产发布、商业验证或已向客户发送。
