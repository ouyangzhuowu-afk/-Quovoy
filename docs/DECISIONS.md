## 存储与迁移差异

本地 SQLite 和本地磁盘适合单实例演示。Postgres 迁移不是替换一个连接字符串：需要迁移表与索引、替换同步 SQL 方言、验证事务／并发锁与唯一约束、迁移组织归属与原文引用，并复跑隔离、版本、幂等和金额测试。部署不能使用短生命周期或多副本各自独立的本地磁盘存放数据库和附件。

持久化任务记录证明作业可见和可手工重试，不能自动等同于具备可靠后台调度。上线前要验证进程中断后的运行中任务恢复及多人重试行为。文件备份必须与数据库关联记录保持一致。

## 数据与模型假设

- 首轮只提取文字明确给出的信息，不猜测材料等级、单位、成本、币种、交付或付款。
- 文件和邮件是非可信业务输入。其内容不能改变系统角色或权限，不能调用工具、执行文件宏／脚本或自动外发。
- 模型字段的来源需与实际解析文本核对。模型自述“高置信度”不是准确率证据。
- 真实 Provider 请求可能将输入发送给配置的模型服务。正式客户数据使用前，由客户确定允许的数据范围、服务商和保留规则。缺少授权时继续使用合成数据或已获许可的脱敏样本。
- 规则和合成样本可检验产品链路，无法估计任意真实询价的模型准确率。
