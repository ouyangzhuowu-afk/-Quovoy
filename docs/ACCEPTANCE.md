## 发现、修复和回归

| 发现 | 修复后的行为 | 验证 |
| --- | --- | --- |
| 去重哈希无组成边界，不同输入可能被误认相同 | 规范结构及文件摘要明确组成边界 | 去重边界回归 |
| 修订客户使旧报价抬头漂移 | 服务端冻结客户名称，拒绝客户端伪造 | 客户快照回归 |
| 重试覆盖人工空行、旧尝试晚返回覆盖较新结果 | 核对人工修订及作业尝试归属 | recovery回归 |
| 切公开标记后历史演示身份仍可能有效 | 登录和会话恢复均拒绝演示身份 | 安全回归 |
| 未知成本不能保存已有工作 | 独立暂存，不以0替代空白，不产生算价结果 | 测试与浏览器刷新 |
| localhost内部URL与127.0.0.1浏览器来源不一致 | 优先APP_ORIGIN，否则按实际Host校验，仍拒恶意来源 | 浏览器及HTTP回归 |
| 自动英文稿可能停留旧金额／条款 | 新版重新生成未改动自动稿，人工稿及历史版本保留 | 邮件版本回归 |
| 样本切换后旧详情请求覆盖新询价，URL与内容错配 | 跟踪当前选中ID并校验响应归属 | 损坏→扫描→损坏双向切换，URL／RFQ／原文一致，询价数仍13 |
| 日期显示不含年份，跨年跟进易误读 | 日期展示加入年份 | 修复后浏览器页面文本；原延期值保留真实2027年 |

实施早期依赖审计发现漏洞、CSS未完成时构建失败、沙盒监听端口报EPERM；后续升级锁定依赖、交付完整前端，并在受控权限下启动本地服务。这些阶段失败已处理，最终结果以上述日志为准。
