## 浏览器发现的缺陷与验证

1. **同源请求被误拒。** Next内部URL为localhost，浏览器地址为127.0.0.1。修复为明确APP_ORIGIN优先，否则按实际Host校验。修复后继续主流程；API回归同时验证正常来源200、恶意来源403且无修改。
2. **旧自动邮件金额可能保留。** 未修改的自动稿现在随新版金额／条款重新生成，明确手写稿保留，各版本独立冻结。自动化回归从381.94改为555.56并核对条款和历史；这不是主流程浏览器报价金额。
3. **样本切换详情错配。** 旧selected闭包发出的refresh曾覆盖新选询价，使URL和页面不一致。现在以当前选中引用和响应归属校验阻止旧响应覆盖；B15双向切换通过。
4. **跨年日期难辨认。** 日期显示加入年份。保留真实2027延期值，不修改数据去迎合预期截图。
